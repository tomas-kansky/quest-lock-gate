# Work Logs (Denní záznamy implementace)

Tato složka obsahuje denní záznamy implementačních prací v souladu s agentským standardem frameworku.

## Pravidla vedení
1. **One per day:** Jeden soubor pro každý kalendářní den (`YYYY-MM-DD.md`).
2. **Inkrementální doplňování:** Nové úkoly v rámci dne se dopisují na konec souboru.
3. **Přesné timestampy:** Každý blok uvádí časové rozmezí `[HH:MM – HH:MM]` a vyčíslenou délku trvání.
4. **Vazba na commity:** Každý blok uvádí dotčené soubory a příslušný Git commit.
